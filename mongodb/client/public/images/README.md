1. Save the livestock monitoring image as `smart-livestock-monitoring.jpg`
2. Save the crop prediction dashboard image as `crop-prediction-dashboard.jpg`
3. Place both files in this `/public/images/` directory

The gallery will automatically display these images with proper titles and descriptions.
